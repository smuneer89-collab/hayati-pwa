# حياتي V10.2

الإصدار يواصل قارئ المصحف QCF من مجلد `quran/` ويضيف:
- توزيع سطور المصحف على كامل ارتفاع شاشة الهاتف.
- واجهة Mobile-only بعرض هاتف ثابت ومنع التكبير التلقائي عند الحقول، مع السماح بـ Pinch Zoom يدويًا.
- إصلاح النسخ الاحتياطي على iPhone باستخدام ورقة المشاركة ثم «حفظ في الملفات»، مع fallback للتنزيل.
- استعادة ZIP، آخر نسخة، تذكير أسبوعي، وإنشاء/استعادة آخر 5 نسخ محلية.
- حفظ تقدم القرآن والمفضلة والعلامات ضمن النسخ الاحتياطية.
- السحب من اليسار إلى اليمين للصفحة التالية.

## خطوط القرآن
ضع الملفات `QCF2001.ttf` حتى `QCF2604.ttf` داخل مجلد `quran/` في جذر المشروع.
