# حياتي — V1 (تحديث مالي: دورتان شهريتان)

هذه النسخة تبني قسم **مالي** حسب الدورة الفعلية للشهر:

- مبلغ حالي قابل للتعديل يدويًا.
- راتب يوم 15 من كل شهر.
- راتب في نهاية كل شهر.
- مصاريف ثابتة لبداية الشهر أو منتصفه مع يوم استحقاق اختياري.
- نافذة «المتاح حتى الراتب القادم» بعد حجز المصاريف والالتزامات غير المدفوعة.
- جدول مالي مقسوم إلى الفترة 1–14 والفترة 15–نهاية الشهر.
- تسجيل استلام كل راتب مرة واحدة في الشهر.
- تعليم المصروف الثابت أو الالتزام بأنه «تم الدفع» مع تحديث الرصيد الحالي تلقائيًا.
- النوافذ العلوية: المبلغ الحالي، المصاريف الثابتة، راتب الشهر، مصروف هذا الشهر.
- بقية أقسام حياتي والنسخ الاحتياطي تبقى كما هي.

لا يوجد Firebase في هذه المرحلة. البيانات محفوظة محليًا في الجهاز، مع نظام النسخ الاحتياطي الموجود في الإعدادات.
