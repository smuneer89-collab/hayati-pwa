# Hayati V9.1 — Uthmanic Quran font

هذه النسخة تبقي قارئ V9 المستقل كما هو، وتغيّر طبقة عرض القرآن فقط إلى خط Uthmanic Hafs (QPC Hafs) من Quran Foundation CDN.

- نص القرآن مدمج داخل `quran.html` وقابل للنسخ.
- لا يوجد API لجلب الآيات ولا `fetch` لملف القرآن.
- إذا تعذر تحميل الخط لأي سبب، يبقى النص ظاهرًا بخط احتياطي.
- لا حاجة إلى مجلد `data` لتشغيل المصحف في هذه النسخة.
