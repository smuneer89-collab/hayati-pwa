# حياتي V10.3 — حديث اليوم + الآيات + نسخ للذكاء الاصطناعي

هذا الإصدار مبني على V10.2 ويحافظ على قارئ المصحف ومجلد `quran/` كما هما.

## الجديد
- حذف عبارة «قبس اليوم» من بطاقة حديث اليوم.
- زران في محرر الحديث: `﴿ فتح آية` و`إغلاق آية ﴾`.
- أي نص يوضع بين القوسين يُطابق محليًا مع قاعدة القرآن العثمانية المدمجة (6236 آية).
- عند وجود تطابق واحد موثوق، يستبدل حياتي النص داخل القوسين بالرسم العثماني ويعرضه بالأخضر الفاتح.
- إذا لم يجد تطابقًا أو وجد أكثر من احتمال، يمنع الحفظ بدل التخمين.
- معاينة المجموعة تعرض الآيات بعد تحويلها قبل الحفظ.
- أزرار حديث اليوم: نسخ، مشاركة، مفضلة، و«نسخ للذكاء الاصطناعي».
- زر الذكاء الاصطناعي ينسخ القالب المتفق عليه كاملًا ويضع الحديث تلقائيًا في نهايته.

## الرفع إلى GitHub
ارفع ملفات هذا الإصدار إلى جذر فرع `Dev` واستبدل الملفات القديمة. لا تحذف مجلد `quran/` ولا ملفات QCF الموجودة داخله.

الملفان الجديدان المستخدمان في هذا الإصدار هما `app-v103.js` و`styles-v103.css`.
