# حياتي — V1 الأقسام الستة + النسخ الاحتياطي

نسخة تجريبية محلية قبل Firebase.

## الأقسام المفعلة
- مالي
- صحتي
- ديني
- معرفتي
- علاقاتي
- عائلتي

## النسخ الاحتياطي
- تصدير ZIP كامل يشمل بيانات التطبيق وصور الألبومات العائلية.
- استعادة ZIP بعد فحصه وإنشاء لقطة أمان محلية.
- الاحتفاظ بآخر 5 لقطات محلية من البيانات النصية.

> البيانات النصية محفوظة في localStorage، وصور العائلة في IndexedDB. Firebase غير مربوط بعد.
