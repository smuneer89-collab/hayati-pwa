حياتي PWA — v10.6 Finance Upgrade

تم تطوير قسم «مالي» ليعتمد على فترات الرواتب المرنة:
- عدد غير محدود من الرواتب مع مبلغ ويوم مستقلين وقابلين للتعديل.
- ربط وتقسيم المصروفات الثابتة بين الرواتب.
- حجز المصروفات المتغيرة المستقبلية فقط عند دخول فترة الراتب التي تقع فيها.
- أهداف مالية بحساب شهري تلقائي من المتبقي والمدة.
- ادخار عام شهري مستقل عن الأهداف.
- حساب المسموح اليومي لكل فترة راتب.
- تنبيه تجاوز الإنفاق اليومي.
- ترحيل بيانات الرواتب القديمة تلقائيًا عند فتح النسخة.

ملاحظة: تخزين قسم «مالي» في هذه الحزمة ما زال محليًا مثل النسخة الأصلية، ولم تتم إضافة إعدادات Firebase جديدة لأن الحزمة لا تحتوي إعداد اتصال Firebase جاهزًا.
