# حياتي V10.1 — المصحف من مجلد quran

هذه النسخة هي نفس V10، لكن تم تغيير طريقة تحميل خطوط المصحف بالكامل:

- لا تستخدم ملفات `.pack`.
- لا تستخدم `qcf-font-manifest-v10.js`.
- كل صفحة تقرأ خطها مباشرة من مجلد `quran`.
- اسم الخط يعتمد على رقم الصفحة:
  - الصفحة 1 → `quran/QCF2001.ttf`
  - الصفحة 100 → `quran/QCF2100.ttf`
  - الصفحة 604 → `quran/QCF2604.ttf`
- الموقع لا يحمل 604 خطًا دفعة واحدة؛ يحمل خط الصفحة المفتوحة فقط ويجهز الصفحة التالية في الخلفية.
- اتجاه السحب كما تم اعتماده: الصفحة التالية بالسحب من اليسار إلى اليمين.

## طريقة الرفع إلى GitHub
1. ارفع ملفات هذه النسخة إلى جذر فرع `Dev` واستبدل الملفات القديمة.
2. افتح مجلد `quran`.
3. ارفع داخله ملفات `QCF2001.ttf` حتى `QCF2604.ttf` الأصلية لديك دون إعادة تسمية.
4. يمكن حذف `quran/README.txt` بعد اكتمال رفع الخطوط؛ وجوده أو حذفه لا يؤثر على القارئ.

لا حاجة لملفات `.pack` القديمة بعد اعتماد هذه النسخة.
