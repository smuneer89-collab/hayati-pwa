# حياتي V9.3 — اختبار تنسيق مصحف عثمان طه

هذه نسخة اختبار لأول خمس صفحات فقط.

التعديلات:
- استخدام خطوط QCF2001–QCF2005 المحلية.
- تصغير/تكبير تلقائي للنص حتى لا يُقص من أعلى أو أسفل الصفحة.
- تحسين المسافات وتوازن الصفحات الكثيفة.
- إبقاء الصفحات الافتتاحية في المنتصف.
- إصلاح علامة نهاية الآية الأولى في صفحة البقرة.
- اتجاه التقليب عربي: السحب لليسار يفتح الصفحة التالية.

هذه ليست النسخة النهائية لـ604 صفحات؛ الهدف ضبط أول خمس صفحات قبل التعميم.
