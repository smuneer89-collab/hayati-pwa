# حياتي V10.4 — إدارة متقدمة لقاعدة الأحاديث

هذا الإصدار يبني على V10.3 ويضيف لوحة إدارة كاملة للأحاديث:

- بطاقات إجمالي الأحاديث / الموضوعات / المفضلة قابلة للفتح والاستعراض.
- قائمة موضوعات مع عدد الأحاديث، وفتح كل موضوع لرؤية أحاديثه.
- إضافة موضوع مستقل، وإضافة حديث لأي موضوع.
- حذف أي حديث من القاعدة.
- حذف أي موضوع مع كل الأحاديث التابعة له بعد تأكيد واضح.
- نتيجة الفحص (تم اكتشافه / جديد / مكرر) أصبحت قوائم قابلة للفتح.
- يمكن حذف أي حديث من دفعة الفحص قبل إضافتها.
- الأحاديث الجديدة تدخل فورًا في قاعدة حديث اليوم.

مجلد quran وخطوط QCF لا يتغيران في هذا الإصدار.
